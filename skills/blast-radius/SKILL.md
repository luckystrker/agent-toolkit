# Радиус поражения

«Тесты зелёные» говорит о том, что проверили. Радиус поражения говорит о том, **что может сломаться из-за этого изменения** — включая то, что тесты не видят. Отвечает на вопрос владельца: «насколько страшно это выкатывать?»

Вход: дифф (`git diff <точка>...HEAD`) или тикет до начала работы (тогда — прогноз).

## Процесс

1. **Что изменено.** Публичные интерфейсы, функции, схемы данных, конфиги, зависимости — списком из диффа, не по памяти.
2. **Кто зависит.** Для каждого изменённого публичного символа найди вызывающих (поиск по репо, граф импортов; для API — клиенты, для схемы БД — все читатели таблицы, для конфига — все сервисы, что его читают). Выпиши с путями файлов. Не нашёл способа проверить — «не проверено», а не «никого».
3. **Куда утекает.** Отметь каждый задетый класс:
   - **Данные:** миграции, запись/удаление, формат хранения, кэш.
   - **Деньги:** платежи, касса, тарифы, начисления.
   - **Внешние системы:** API партнёров, почта/SMS, вебхуки, очереди.
   - **Доступы:** авторизация, роли, секреты.
   - **Скорость:** горячие пути, запросы в цикле, размер ответа.
   - **Пользователи:** какие экраны/сценарии меняют поведение.
4. **Обратимость.** Для каждого класса: откатывается ли откатом кода? Миграция с удалением столбца, отправленное письмо, проведённый платёж — **необратимы**.
5. **Оценка.** По шкале конвейера (частота 1–5 × вред 1–10; деньги/данные — вред 10) для худшего правдоподобного сбоя.

## Выход

```markdown
## Радиус поражения: <дифф/тикет>
- Изменено: …
- Зависят: <файл — как>; не проверено: …
- Задето: данные ✓ / деньги ✗ / внешние ✓ / доступы ✗ / скорость ✓ / пользователи ✓
- Необратимое: <что> → нужен человек: да/нет
- Худший сбой: <сценарий> — риск <ч×в>
- Сценарии для приёмки: S-<n> <что прогнать, чтобы увидеть, что задетое цело>
- Нужен замер скорости: да/нет (горячие пути: …)
```

## Что из этого следует

- Сценарии — во вход `acceptance`/`interrogate`: проверяющий прогоняет их и сохраняет артефакты.
- Необратимое → путь в `.agents/gate.json: protected` (если ещё не там) и `human: required` в тикете. Предложи пользователю — не добавляй молча.
- Задета скорость → замер в `release-train` обязателен.
- Радиус шире тикета (задеты модули из «Не трогать» других тикетов) → сообщи тимлиду (`board msg teamlead`), параллельные агенты могут столкнуться.

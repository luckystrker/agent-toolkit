# Тезаурус

> Одно понятие — одно имя. Синонимы из колонки «не говорить» в коде, тестах и документах не используются.
> Изменение определения — пометкой с датой в конце статьи, не молча.

## <Понятие>

- **Что это:** <одна фраза простыми словами>
- **В коде:** `<Тип>` / таблица `<имя>` / модуль `<путь>`
- **Не говорить:** <синоним 1>, <синоним 2>
- **Связи:** <принадлежит X>, <состоит из Y>, <не путать с Z — чем отличается>

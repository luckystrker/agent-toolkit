# Цикл приёмки кода

Защита от главного обмана: «зелёные тесты» написанные тем же исполнителем под его же код. Тесты пишет отдельная роль, и их атакует отдельная роль.

## Роли (субагенты через Agent tool, тип general-purpose, роли задаются промптом)

Каждая роль — **отдельный запуск субагента со свежим контекстом**. Критик не должен видеть переписку тестировщика: ему передаются код, дифф, спецификация и готовые тесты — без хода их создания, иначе он «пропитается» логикой исполнителя и пропустит подгонку.

- **Тестировщик** — пишет тесты ПО СПЕЦИФИКАЦИИ, не по коду: property-based (fast-check для TS, hypothesis для Python, proptest для Rust — что найдётся в проекте) + краевые случаи из чек-листа/спеки. Свежий взгляд: не подглядывать в реализацию «как удобно».
- **Критик** — атакует тесты тестировщика, не код: покрытие диффа ≥ 80%; тесты не подогнаны под реализацию (предложить 2–3 точечные мутации кода — каждая обязана валить хотя бы один тест; выжившая мутация = дыра); пропущенные краевые случаи; asserts, которые всегда истинны.

## Цикл

1. Собери контекст: дифф/изменённые файлы, пункт чек-листа, соответствующий раздел спецификации.
2. **Тестировщик** пишет тесты и прогоняет. Красные тесты = находки, не «почини под код» (если код не соответствует спеке — это баг кода).
3. **Критик** ревьюит тесты по критериям выше. Замечания → обратно тестировщику.
4. Цикл ≤ **3 итераций**. Не сошлись — стоп, докладывай спор пользователю с позициями сторон.
5. **Гейт:** линтер + проверка типов + юнит-тесты зелёные из чистого состояния (те же команды, что в pre-commit-х уке проекта, если он есть).
6. **Зелёные тесты тестировщика без вердикта критика не принимаются никогда.**

## Отчёт «готово к ручной приёмке»

После цикла — короткий отчёт:
- **Проверено:** чем и как (какие тесты, какое покрытие, мутации убиты).
- **Не проверено:** что осталось за рамками автоматизации.
- **Как проверить руками:** конкретная команда/шаги и ожидаемый наблюдаемый результат.
- **Оговорки:** известные шероховатости, допущения.

Только после этого — коммит (гейт-хук догонит, если что забыл).

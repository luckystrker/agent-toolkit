# Ресёрч по первоисточникам

Запусти **фонового агента** (Agent tool с run_in_background, или Explore для поиска по репозиторию) — сам продолжай работать, пока он читает.

Его работа:

1. Исследовать вопрос по **первоисточникам** (официальная документация, исходный код, спецификации, API первых сторон), а не по пересказам. Каждое утверждение откатывается к источнику, который им владеет. Инструменты: WebSearch для поиска, WebFetch / web-reader для чтения страниц; если источник не открывается — так и записать, не заменять пересказом молча.
2. Записать находки одним Markdown-файлом, каждое утверждение — со ссылкой на источник (URL + название; для кода — файл/строка).
3. Сохранить там, где репо уже хранит такие заметки (обычно указано в `AGENTS.md`; типовое место — `docs/research/<тема>.md`). Конвенции нет — положи в разумное место и скажи куда.

Формат находок:

````markdown
# <Вопрос>

## Ответ (коротко, 3–5 строк)

## Детали
- Утверждение — [источник](url)

## Не удалось проверить
- Что и почему (закрыто/нет доступа/противоречиво)
````

Не подмешивать мнение без пометки «интерпретация» — факты и интерпретации различимы.

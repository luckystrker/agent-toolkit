# Handoff: передача сессии

Свежая сессия не имеет твоего контекста. Напиши документ, по которому она продолжит работу без потерь и без пересказа истории.

## Что записать

Файл `HANDOFF.md` в корне проекта (обновляй существующий, не плодить копии):

```
# Handoff — <дата>

## Статус
<одним абзацем: над каким этапом/пунктом чек-листа работаем, общий режим (зелёное/красное)>

## Сделано
- <пункт чек-листа / коммит — что именно, ссылка на файл/коммит>

## Не доделано (где именно остановился)
- <файл:строка, что происходит, что мешает — точнее, чем «почти готово»>

## Следующий конкретный шаг
<одна фокусированная задача, с которой стартует новая сессия>

## Открытые вопросы
- <что требует решения пользователя или внешней информации>
```

## Правила

- Пиши факты и ссылки (файлы, коммиты, команды), не пересказывай рассуждения.
- «Не доделано» — с точностью до файла и строки; незакрытый edit/тест описать явно.
- Проверь, что статус чек-листа соответствует реальности (сделанное отмечено).
- Если работа велась вне чек-листа — это сигнал: зафиксируй пункт в бэклоге.
- Не начинай новых задач после handoff, если пользователь не попросил.
